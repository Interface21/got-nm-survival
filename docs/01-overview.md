# ภาพรวมผลิตภัณฑ์

## ปัญหาที่แอปแก้

โหมด Nightmare Survival มีด่านเปลี่ยนทุกสัปดาห์ ด่านหนึ่งมี 4 เวฟ แต่ละเวฟมี 3 เวฟย่อย (รวม 12 เวฟย่อย) ศัตรูเกิดจากสถานที่ 3 แห่งในด่าน แต่ละแห่งมีฝั่งซ้าย กลาง ขวา ผู้เล่นที่รู้ลำดับการเกิดล่วงหน้าจะวางตำแหน่งได้ถูก แอปนี้ให้ผู้เล่นช่วยกันจดลำดับการเกิดของสัปดาห์นั้น แล้วเปิดดูระหว่างเล่นจริง พร้อมเสียงอ่านและตัวจับเวลาต่อเวฟย่อย

## ผู้ใช้

- ผู้เล่นทั่วไป: เปิดดูระหว่างเล่น (ส่วนใหญ่บนมือถือ วางข้างจอเกม) และช่วยบันทึกจุดเกิดที่เห็น ไม่ต้องล็อกอิน
- แอดมิน: ล็อกอินด้วยรหัสผ่าน แก้ข้อมูลทั้งด่านในเครื่องก่อนแล้วกด Save ครั้งเดียว ล้างข้อมูลได้ เปลี่ยนด่านได้แม้มีข้อมูลแล้ว

## คำศัพท์ในโดเมน

| คำ | ความหมาย |
|---|---|
| ด่าน (map) | Hidden Temple, River Village, Frozen Valley, Broken Castle ด่านประจำสัปดาห์มีด่านเดียว |
| เวฟ (wave) | W1 ถึง W4 |
| เวฟย่อย (subwave) | 1.1, 1.2, 1.3 ... 4.3 รวม 12 ช่อง |
| จุดเกิด (spawn point, slot) | ลำดับที่ 1..3 ในเวฟย่อย (เวฟ 4 มี 4 ลำดับ) |
| สถานที่ (location, loc) | 3 แห่งต่อด่าน เช่น Cemetery, Pagoda, Courtyard |
| ฝั่ง (side) | L / C / R (ซ้าย กลาง ขวา) บางสถานที่มีแค่ 2 ฝั่ง เช่น Waterfalls มีแค่ L/R |
| สีออร่า (aura color) | ใช้เฉพาะ Hidden Temple: ส้ม ฟ้า เขียว เวฟ 1-3 เลือกได้ 1 สี เวฟ 4 ได้ 2 สี |
| ทีม (team) | A / B แบ่งว่าจุดไหนทีมไหนรับผิดชอบ |
| รอบสัปดาห์ (reset week) | นับจากวันจันทร์ 22:00 น. เวลาไทย ระบุด้วยวันที่ `d/m/yyyy` ของวันจันทร์นั้น |

## ฟีเจอร์ทั้งหมด

### การดูข้อมูล (5 แท็บ)

1. ไอคอน (`list`): การ์ดต่อเวฟ แถวละเวฟย่อย แต่ละจุดเป็น emoji ของสถานที่ + ป้ายฝั่ง L/C/R + จุดสีออร่าใต้ไอคอน จุดว่างแสดงวงประ `?`
2. ตัวหนังสือ (`text`): แบบเดียวกันแต่เป็นชื่อย่อ เช่น `โรง-ซ้าย` หรือ `Forge-L` อ่านเร็วกว่าเมื่อจอเล็ก
3. แผนที่ (`map`): ภาพแผนที่ SVG ของด่าน หมุดมีเลขลำดับวางตรงจุดเกิดจริง ใต้แผนที่เป็นตาราง 12 เวฟย่อย (4 แถว x 3) กดเลือกได้ทันที
4. แบ่งทีม (`team`): แตะจุดเพื่อวนค่า ว่าง → A → B บันทึกให้ทุกคนอัตโนมัติ
5. ตั้งค่า (`settings`): ชื่อด่าน, ปุ่มเปลี่ยนด่าน, จำนวนผู้เข้าชม, สัปดาห์, คำอธิบายไอคอนและคำย่อ, เสียง, ภาษา, ความเร็วเสียง, ธีม, แชร์ QR, What's New, แอดมิน

แถบแท็บตรึงอยู่บนสุดตอนเลื่อน ใต้แท็บมีแถบ "ทีมของฉัน" (ทั้งหมด / ทีม A / ทีม B) แสดงเฉพาะสัปดาห์ที่มีการแบ่งทีมและอยู่ในแท็บไอคอน ตัวหนังสือ หรือแผนที่ แท็บที่เลือกจำไว้ในเครื่อง

### ระหว่างเล่น

- แตะแถวเวฟย่อย: เริ่มนับถอยหลัง (เวฟ 1-3 = 90 วินาที, เวฟ 4 = 120 วินาที) เลขเวฟย่อยกลายเป็นนาฬิกา และอ่านจุดเกิดออกเสียงถ้าเปิดเสียงไว้
- หมดเวลาแล้วขยับไปเวฟย่อยถัดไปเอง พร้อมอ่านเสียงใหม่
- แตะแถวเดิมซ้ำ: หยุดนับ
- โหมดโฟกัส: เวฟที่กำลังเล่นยกเงา เวฟอื่นจางเหลือ 40%
- เลือกทีมของฉันแล้ว: จุดของอีกทีมจางเหลือ 25% และเสียงอ่านเฉพาะจุดของทีมเรา

### การบันทึก (ผู้เล่นทุกคน)

- ปุ่มดินสอท้ายแถวเวฟย่อย เปิด sheet แก้ไขเต็มความสูงใต้แถบแท็บ
- แต่ละจุด: เลือกสถานที่ (ปุ่ม 3 ช่องมี emoji + ชื่ออังกฤษ + ชื่อไทยเต็ม) → เลือกฝั่ง → (Hidden Temple) เลือกสี
- บันทึกเองทีละจุดหลังหยุดแตะ 1.5 วินาที แสดงสถานะต่อจุด: รอบันทึก, กำลังบันทึก, บันทึกแล้ว, ไม่สำเร็จ (แตะเพื่อลองใหม่)
- ปิด sheet ก่อนครบเวลา: ส่งจุดที่ค้างทันที

### รอบสัปดาห์และด่าน

- เข้าแอปครั้งแรกของสัปดาห์ใหม่ (ยังไม่มีใครเลือกด่าน): แจ้งเตือน "รีเซ็ตสัปดาห์ใหม่" 5 วินาที และเปิดหน้าต่างเลือกด่านทันที
- ผู้เล่นคนไหนก็เลือกด่านได้ ไม่ต้องรอแอดมิน
- เปลี่ยนด่านได้จนกว่าจะมีคนบันทึกเวฟแรก หลังจากนั้นล็อก (แอดมินยังเปลี่ยนได้)

### อื่น ๆ

- TH / EN สลับได้ มีผลกับชื่อแท็บ ชื่อจุดเกิด แผนที่ และเสียง
- Dark / Light ตามระบบในครั้งแรก แล้วจำค่าที่เลือก
- ตัวนับผู้เข้าชม (เพิ่มทุกครั้งที่โหลดแอป)
- QR code สำหรับแชร์ ดาวน์โหลดเป็น PNG ได้
- What's New แสดงเองครั้งแรกต่อเครื่องต่อเวอร์ชัน เปิดซ้ำได้จากตั้งค่า

## Flow หลัก

### เปิดแอป

```
โหลด overlay "CONNECTING..."
  → getWeeklyMapData (ได้ config ด่าน + ข้อมูลสัปดาห์นี้ + นับผู้เข้าชม)
  → เลือกด่านที่จะแสดง: ด่านของสัปดาห์ในระบบ > ด่านที่จำในเครื่อง > ด่านแรก
  → ซ่อน overlay, render()
  → ยังไม่มีด่านของสัปดาห์?  ใช่ → แจ้งเตือนสัปดาห์ใหม่ + เปิดหน้าต่างเลือกด่าน (ปิดได้ แต่จะเด้งกลับเมื่อพยายามบันทึก)
  → มีด่านแล้วและยังไม่เคยเห็น What's New v3?  ใช่ → เปิด What's New (หน่วง 600ms)
                                              ไม่ → ถามทีม (ถ้าสัปดาห์นี้มีการแบ่งทีมและยังไม่เคยตอบ)
  → ปิด What's New → ถามทีม
```

modal ถูกเปิดทีละอันเสมอ ถ้ามี modal อื่นเปิดอยู่ หน้าต่างถามทีมจะรอไว้ก่อน

### กลับเข้าแอป (สลับแอปไปเล่นเกมแล้วกลับมา)

`visibilitychange` → ถ้าไม่ใช่แอดมินและ sheet แก้ไขไม่ได้เปิดอยู่ → ดึง `getLatestSpawnData` แล้ว render ใหม่ ถ้ามีคนอื่นเลือกด่านไปแล้วขณะที่หน้าต่างเลือกด่านเปิดค้าง ระบบปิดหน้าต่างให้เอง

### บันทึกจุดเกิด

```
แตะดินสอ → ยังไม่มีด่าน? → เปิดหน้าต่างเลือกด่าน
         → เปิด sheet ด้วยข้อมูลที่มีในเครื่อง แล้วโหลดล่าสุดจาก server
         → แตะเลือก → เก็บเข้าคิวของจุดนั้น (debounce 1.5s)
         → ครบเวลา: ค่าเท่ากับที่บันทึกแล้ว? ไม่ส่ง : ส่ง saveSpawnPoint
         → สำเร็จ: ใช้ข้อมูล latest ที่ server ส่งกลับมา render ใหม่ทั้งหน้า
         → ด่านถูกเปลี่ยน / ยังไม่มีด่าน: ทิ้งคิวทั้งหมด ปิด sheet โหลดใหม่ แจ้งผู้ใช้
         → ผิดพลาดอื่น: สถานะจุดเป็น "ไม่สำเร็จ แตะเพื่อลองใหม่"
```

### แอดมิน

```
ตั้งค่า → Admin Login → ใส่รหัส → checkAdminPassword
  → เข้าโหมดแอดมิน: ซ่อนแถบแท็บ, แสดงแถบเครื่องมือล่าง (Clear / Save / Exit), dropdown เลือกด่านใช้ได้
  → แตะแถวเวฟย่อย = เปิด sheet แก้ไข (แก้ในเครื่อง ไม่ส่งทีละจุด)
  → Save → saveWeeklyMapData (เขียนทั้งแถวทับ)
  → Exit โดยยังไม่ Save → ถามยืนยัน → คืนค่าที่สำรองไว้ตอนล็อกอิน
```
